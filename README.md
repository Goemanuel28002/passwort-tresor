# Passwort-Tresor

Ein verschlüsselter Passwort-Manager als einzelne HTML-Datei (`index.html`).

- Verschlüsselung: AES-256-GCM, Schlüsselableitung mit PBKDF2 (SHA-256).
- Alles läuft lokal im Browser. Es werden keine Daten gesendet.
- In diesem Repository liegt nur die App. Die Passwörter stehen in deiner eigenen, verschlüsselten Tresor-Datei (`.pwv`) und niemals hier.
